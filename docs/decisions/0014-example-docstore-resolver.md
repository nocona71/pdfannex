# 0014 Example docstore resolver and `\NewAnnexSource`
- Context: the goal is simple extensibility and the same command pattern for different PDF sources. A file adapter does not show that: plain paths are already read by the package (self-contained CTAN use), and the CLI already hashes and locks. A numeric-only adapter was too thin to be a template.
- Decision:
  1. `\NewAnnexSource{\cmd}{scheme}` in `pdfannex.sty` defines `\cmd[opts]{ref}{title}` as `\includeannex[opts]{pdfannex://scheme/ref}{title}`. The scheme is any name; the package never validates or knows adapters. Adapter discovery stays in the CLI (`pdfannex-resolver-SCHEME` on `PATH`).
  2. `adapter-example/pdfannex-resolver-docstore` is the showcase and fork-start. It serves `pdfannex://docstore/<id>[?rev=n]` from an HTTP document service (curl; configured by `PDFANNEX_DOCSTORE_URL`/`_TOKEN`), with a mock server `docstore_server.py` that has fault injection for tests. It shows source options, pinning a floating request to a revision (`resolved`), `status` update detection, error codes and environment configuration. An optional `adapter-example/pdfannex-docstore.sty` shows an adapter-specific command name.
  3. The example has its own module tests (`adapter-example/test_docstore.py`, run by `scripts/check`) that cover the adapter without the CLI: tampered or deleted revisions, symlinks, bad options, protocol errors. Adapter authors are expected to ship such tests with their adapter.
  4. Adapters are not shipped in the CTAN archive; the example lives in `adapter-example/`, a self-contained directory with no dependency on the rest of the repository (own JSON/SHA helpers, conformance script, module tests, README), meant to be copied as the template for community adapters and is covered by `testfiles/test_cli.py`.
- Possible future extension: a `scheme=` key (document default or per call) that prepends `pdfannex://<scheme>/` to non-URI sources. Not needed while `\NewAnnexSource` covers it, and a document default would make plain paths ambiguous (they would need an explicit escape such as `scheme=file`).
- Consequences: a new adapter needs no change to the package; mixed-source documents use one lock and one map.
