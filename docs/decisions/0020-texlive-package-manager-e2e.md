# 0020 TeX Live package-manager end-to-end tests

- Context: decision 0019 added fast isolated layout/install tests and CTAN archive end-to-end tests. Those tests did not prove that TeX Live's package manager could install the core package or resolve the adapter's declared dependency.
- Decision: keep the fast package-layout tests and the CTAN archive tests. Add two end-to-end flows, each in its own fresh container running a pinned native TeX Live 2025 installation. The core flow builds a relocatable TeX Live package container from the core TDS archive, installs it with `tlmgr --usermode`, and compiles a local-PDF inclusion. The adapter flow builds a local TeX Live repository from both TDS archives, declares `pdfannex-docstore` dependent on `pdfannex`, installs only the adapter with normal `tlmgr`, and verifies that both packages are installed before testing local- and docstore-PDF inclusions through a locked rebuild.
- Consequences: these tests exercise actual TeX Live package-manager behavior without changing the project's published CTAN or TDS artifacts. The adapter flow proves automatic dependency resolution. Keep the two installations in separate containers so neither test can inherit packages from the other. This supersedes decision 0019's deferral of `tlmgr` testing; CTAN ZIPs remain distinct from TeX Live package containers.
