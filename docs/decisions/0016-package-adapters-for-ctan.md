# 0016 Package adapters for CTAN distribution

- Context: Resolver Protocol 1 adapters extend pdfannex without adding source-specific logic to the core package. The adapter example is intended as a fork-start, and users need a practical way to install adapters. CTAN can host scripting-language executables, but CTAN hosting and inclusion in TeX Live are separate decisions. TeX Live recommends TeXLua scripts and expects installed scripts to be discoverable and self-locating. The docstore example additionally depends on `curl`, which TeX Live does not guarantee.
- Decision:
  1. Treat separately installable CTAN packages as the intended distribution model for adapters. An adapter package may provide an adapter-specific `.sty`, its `pdfannex-resolver-SCHEME` executable, required helper files, and user documentation. For the docstore package, use `tex/latex/pdfannex-docstore/` for the `.sty` and `scripts/pdfannex-docstore/` for the resolver and helper.
  2. Keep adapters independent of core source-specific behavior. The CLI discovers a resolver by scheme when needed, using the `pdfannex-resolver-SCHEME` name on `PATH`; it does not scan or register adapters at startup. The base pdfannex distribution must provide the CLI for an adapter package to be useful. Package the CLI and its support files under the TDS path `scripts/pdfannex/`; use Kpathsea as a fallback to locate support files when a distribution invokes a script through a `bin` link.
  3. Document adapter-specific external dependencies. The docstore adapter may require `curl`; if it is unavailable, the resolver should report a specific missing-dependency message and advise installing curl and making it available on `PATH`.
  4. Keep CTAN submission and TeX Live inclusion as separate follow-up decisions. Before distribution, verify that the package layout installs the resolver where the CLI can find it and that its runtime dependencies and platform limitations are clearly documented.
- Consequences: adapter users can install source support separately from the core package, while plain-file use and locked builds do not acquire adapter dependencies. CTAN packaging does not by itself guarantee TeX Live inclusion or install external tools such as curl.
- Supersedes decision 0014 only on its statement that adapters are not shipped in CTAN packages; its design of `\NewAnnexSource` and the self-contained adapter example remains in effect.
