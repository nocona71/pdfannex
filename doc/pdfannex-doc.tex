\section{Overview}

\texttt{pdfannex} includes PDF files as annexes using \texttt{pdfpages}. Each
annex gets a hyperlink target, a PDF bookmark, an entry in an automatic list of
annexes and a label usable in cross references. It works with pdfLaTeX,
LuaLaTeX and XeLaTeX and does not depend on the document class.

Annex numbers and pages are stored in the \texttt{.aux} file, so run \LaTeX{}
twice; references show \texttt{??} on the first run.

\section{Usage}

\begin{verbatim}
\usepackage{pdfannex}
...
\listofannexes
\includeannex[label=cv,layout=footer-safe]{cv.pdf}{Curriculum vitae}
See \annexref{cv} on page \annexpageref{cv}.
\end{verbatim}


\verb|\includeannex[|\emph{options}\verb|]{|\emph{file}\verb|}{|\emph{title}\verb|}|
includes all pages of \emph{file} (or those selected by \texttt{pages}) as one
annex.


\verb|\pdfannexsetup{|\emph{options}\verb|}| sets defaults for later annexes.


Prints the list of annexes. \verb|\annexref{|\emph{label}\verb|}| and
\verb|\annexpageref{|\emph{label}\verb|}| give a link to the annex and its
first page.

\section{Page size and scaling}

Annex pages keep the sheet size and orientation of the host document; pages are
never rotated or stretched. Each source page is scaled uniformly to fit the
sheet, and the aspect ratio is preserved.

\textbf{Warning:} \texttt{pdfpages} scales to fit, so source pages smaller than
the host sheet (for example an A5 PDF in an A4 document) are \emph{enlarged}
to fill it, and larger pages are shrunk. Preventing enlargement is not
supported in this version. Pages in the same PDF are fitted independently.

\section{Options}

\begin{description}
\item[\texttt{label}] Label for \verb|\annexref|.
\item[\texttt{pages}] Page range passed to \texttt{pdfpages} (default \texttt{-}).
\item[\texttt{nup}] Several source pages per sheet, passed to \texttt{pdfpages} (for example \texttt{2x1}); the annex page number and \verb|\annexpageref| refer to its first sheet. Combining different files on one sheet is not supported.
\item[\texttt{layout}] \texttt{fullpage} (default), \texttt{footer-safe}
  (scaled down to leave room for the host footer) or \texttt{framed}.
\item[\texttt{margin}, \texttt{footer-space}] Custom margin and footer area;
  the page is scaled uniformly and shifted up. They override the preset
  scale of \texttt{layout}.
\item[\texttt{frame}] Boolean; draw a frame around each page (implied by \texttt{layout=framed}).
\item[\texttt{page-style}] Page style used on annex pages (default \texttt{plain}).
\item[\texttt{pagination}] \texttt{inherit} (default) uses the current page
  counter. \texttt{continue} first ends the current page and continues the page
  counter from the physical pages already output; use it with classes that reset
  the page counter, such as \texttt{scrlttr2} with several letters.
\item[\texttt{bookmark}, \texttt{list}] Boolean; add a bookmark or list entry (default true).
\item[\texttt{annex-name}, \texttt{heading}] Words used in bookmarks and
  list entries (\texttt{Annex}) and the list heading (\texttt{Annexes}).
\end{description}
